# Лист

Лёгкие заметки в браузере, в духе Notion. Страницы, блоки, слэш-меню и тёмная тема работают без сервера и сборки. Данные остаются в `localStorage`.

## Запуск

Откройте `index.html` или поднимите статический сервер:

```bash
python3 -m http.server 4173
```

Затем откройте `http://localhost:4173`.

## Как писать

- `/` открывает меню блоков: текст, заголовки, списки, чекбокс, цитата, выноска, код, разделитель, вложенная страница.
- `#`, `##`, `###`, `-`, `[]`, `>` и `---` в начале строки превращают блок.
- Enter создаёт следующий блок, Backspace в начале строки сливает его с предыдущим.
- Перетащите блок за ручку `⠿` или откройте ею меню блока.
- Ctrl+B / ⌘B — жирный, Ctrl+I / ⌘I — курсив, Ctrl+Z — отмена.
